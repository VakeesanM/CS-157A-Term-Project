# Overview

This is term project for SJSU's CS 157A(Intro to Database Management Courses) done by Esha Hooda & Vakeesan Moorthy.


## How to Run

```bash
pip install -r requirements.txt
type nul > .env
```
```bash
# Download and run the files in sql-set-up in mySQL server
# Write Database info in .env in the following format:
#MYSQL_USER={}
#MYSQL_PASSWORD=
#MYSQL_IP=
#MYSQL_DATABASE=

```
```bash
streamlit run src/main.py
```
